# Reel Insights – TMDB Movie Analytics

An end-to-end movie industry data analytics project using:

- Python
- Pandas
- NumPy
- SQL
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Project Objectives

- Clean and analyse TMDB movie data.
- Perform SQL and Pandas analysis.
- Build meaningful data visualizations.
- Develop an interactive Streamlit dashboard.
